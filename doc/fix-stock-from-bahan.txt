FIX: POST /products/{sku}/sizes/{size_id}/stock-from-bahan mengembalikan 404
==============================================================================

Frontend sudah selesai dan sudah ditest. Endpoint ini dipanggil saat user
scan QR produk → pilih "Dari Produksi" → toggle "Kurangi bahan otomatis" ON
→ tap Simpan. Saat ini endpoint mengembalikan 404 sehingga bahan tidak berkurang.

---

## Apa yang harus dilakukan endpoint ini

1. Tambah stok produk (sama seperti POST /products/{sku}/sizes/{size_id}/adjust-stock,
   dengan reason = "production")
2. Kurangi stok setiap bahan yang ada di PatternSpec sebanyak:
   - Untuk setiap fabric di spec.fabrics:
       deduct_length_cm = fabric.cut_length_cm × qty
       deduct dari material.remaining_length_cm (atau tabel stock fabric)
   - Untuk setiap component di spec.components:
       deduct_qty = component.qty_per_unit × qty
       deduct dari material.current_stock_qty (atau tabel stock hardware)
3. Kembalikan ProductSizeBasic (same shape as GET /products/{sku}/sizes single item)

---

## Request

  POST /products/{sku}/sizes/{size_id}/stock-from-bahan

  Headers:
    Authorization: Bearer <token>
    Content-Type: application/json

  Body:
    {
      "qty": 1,           // int, jumlah pcs yang diproduksi
      "spec_id": "<uuid>" // UUID PatternSpec yang dipakai
    }

### Step 4: Jika handler belum ada — buat baru

Buat endpoint di router yang relevan (kemungkinan app/routers/products.py):

```python
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from pydantic import BaseModel
from uuid import UUID
from app.database import get_db
from app.models import ProductSize, PatternSpec, StockLedger, MaterialLedger
from app.auth import get_current_user

class StockFromBahanRequest(BaseModel):
    qty: int
    spec_id: UUID

@router.post("/{sku}/sizes/{size_id}/stock-from-bahan")
def add_stock_from_bahan(
    sku: str,
    size_id: UUID,
    body: StockFromBahanRequest,
    db: Session = Depends(get_db),
    current_user = Depends(get_current_user)
):
    # 1. Validate size exists and belongs to sku
    size = db.query(ProductSize).filter(
        ProductSize.id == size_id,
        ProductSize.product_sku == sku
    ).first()
    if not size:
        raise HTTPException(status_code=404, detail="ProductSize not found")

    # 2. Validate spec exists and is active
    spec = db.query(PatternSpec).filter(
        PatternSpec.id == body.spec_id,
        PatternSpec.is_active == True
    ).first()
    if not spec:
        raise HTTPException(status_code=404, detail="PatternSpec not found")

    # 3. Add production stock (reuse existing logic for adjust-stock)
    size.current_stock_qty += body.qty
    size.production_stock_qty = (size.production_stock_qty or 0) + body.qty

    # 4. Create stock ledger entry
    ledger = StockLedger(
        product_size_id=size_id,
        change_qty=body.qty,
        reason="production",
        note=f"QR scan produksi · spec {body.spec_id}"
    )
    db.add(ledger)

    # 5. Deduct fabric stock
    for fabric in spec.fabrics:
        deduct_cm = fabric.cut_length_cm * body.qty
        material = fabric.material  # assuming relationship loaded
        if material:
            material.remaining_length_cm = (material.remaining_length_cm or 0) - deduct_cm
            # Add material ledger entry if you have one:
            # mat_ledger = MaterialLedger(material_id=material.id, change_cm=-deduct_cm, reason="production")
            # db.add(mat_ledger)

    # 6. Deduct component/hardware stock
    for component in spec.components:
        deduct_qty = component.qty_per_unit * body.qty
        material = component.material  # assuming relationship loaded
        if material:
            material.current_stock_qty = (material.current_stock_qty or 0) - deduct_qty

    db.commit()
    db.refresh(size)

    # 7. Return ProductSizeBasic — use same serializer as GET /products/{sku}/sizes
    return serialize_product_size_basic(size)
```

PENTING: Sesuaikan field names dan model relationships dengan kode yang sudah ada
di codebase. Lihat handler adjust-stock untuk referensi cara deduct yang benar.
