## Task 1 — GET /reports/dashboard: tambah 5 field month-level

### Problem

iOS menerima decode error `keyNotFound 'month_revenue'` — dashboard dan laporan blank total.

### Response Saat Ini

```json
{
  "today_revenue": 43333.33,
  "today_order_count": 3,
  "today_profit": 17333.33,
  "today_units_sold": 5,
  "low_stock_alerts": []
}
```

### Response yang Diharapkan

```json
{
  "today_revenue": 43333.33,
  "today_order_count": 3,
  "today_profit": 17333.33,
  "today_units_sold": 5,
  "month_revenue": 150000.0,
  "month_orders": 12,
  "month_units_sold": 28,
  "month_batches_confirmed": 2,
  "avg_margin_pct": 0.45,
  "low_stock_alerts": [...]
}
```

### Definisi Field Baru

| Field | Tipe | Query |
|---|---|---|
| `month_revenue` | `float` | `SUM(total_revenue)` dari `sales_order` WHERE `sold_at >= date_trunc('month', NOW())` AND status != 'cancelled' |
| `month_orders` | `int` | `COUNT(*)` dari `sales_order` bulan ini (non-cancelled) |
| `month_units_sold` | `int` | `SUM(qty)` dari `sales_order_item` JOIN `sales_order` bulan ini (non-cancelled) |
| `month_batches_confirmed` | `int` | `COUNT(*)` dari `production_batch` WHERE `status='confirmed'` AND `confirmed_at >= date_trunc('month', NOW())` |
| `avg_margin_pct` | `float` | `AVG(margin_pct)` dari `product_size` WHERE `margin_pct IS NOT NULL`; return `0.0` jika tidak ada rows |

## Task 2 — GET + POST /sales-orders: enrichment fields di items

### Problem

Response items tidak menyertakan `product_name`, `size_label`, `sales_order_id`. Root tidak menyertakan `total_revenue`, `total_profit`. Nama produk di detail order tampil sebagai "Produk · -".

### Item Response Saat Ini

```json
{
  "id": "uuid",
  "product_size_id": "uuid",
  "qty": 2,
  "unit_price": 22000.0,
  "discount": 0.0,
  "unit_hpp_snapshot": 8000.0,
  "line_profit": 28000.0
}
```

### Item Response yang Diharapkan

```json
{
  "id": "uuid",
  "sales_order_id": "uuid",
  "product_size_id": "uuid",
  "product_name": "Scrunchie Satin",
  "size_label": "M · Satin Pelangi",
  "qty": 2,
  "unit_price": 22000.0,
  "discount": 0.0,
  "unit_hpp_snapshot": 8000.0,
  "line_profit": 28000.0,
  "line_revenue": 44000.0
}
```

Derivation:
- `product_name` → `product.name` via `product_size.product_id`
- `size_label` → concat `product_size.size_label` + (` · ` + `product_size.fabric_variant_name` jika tidak null)
- `line_revenue` → `(unit_price - discount) * qty`

### Root Response Tambah 2 Field

```json
{
  "id": "uuid",
  "invoice_no": "INV-...",
  "total_revenue": 44000.0,
  "total_profit": 28000.0,
  ...
}
```

Derivation:
- `total_revenue` → `SUM((item.unit_price - item.discount) * item.qty)` across items
- `total_profit` → `SUM(item.line_profit)` across items
