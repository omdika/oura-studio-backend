# Version 3.50 - Product Size Multi-Image Upload (GCS Proxy)

## 1. Problem / Opportunity
*   **Context:** Saat ini produk aksesori (scrunchies, dll) hanya diidentifikasi menggunakan teks (Nama, SKU, Ukuran, Varian Kain) di aplikasi. Belum ada representasi visual untuk setiap ukuran/varian produk, padahal foto produk sangat penting untuk verifikasi fisik saat pengemasan/penjualan serta meningkatkan estetika antarmuka.
*   **Objective:** Menyediakan mekanisme unggah beberapa foto produk per ukuran/varian (`product_size`) secara langsung dari halaman detail produk ke Google Cloud Storage (GCS) melalui backend FastAPI sebagai secure proxy. Gambar dibatasi bertipe JPEG dengan ukuran maksimum 1.8 MB, dan akan dikompresi otomatis oleh client (iOS) sebelum diunggah jika melebihi batas tersebut.

---

## 2. User Flow & UX Specifications
*   **Entry Point:** Bagian baru **"Foto Produk"** ditambahkan di dalam `ProdukSizeDetailView` (halaman detail varian ukuran produk).
*   **UI Components:**
    *   **Horizontal Scroll Grid / Carousel:** Menampilkan thumbnail foto-foto yang sudah diunggah untuk ukuran tersebut.
    *   **Empty State:** Jika belum ada foto, tampilkan placeholder ilustrasi kamera dengan teks *"Belum ada foto untuk ukuran ini"*.
    *   **PhotosPicker (iOS 16+):** Tombol bulat berbentuk kartu berkamera dengan ikon `+` untuk memilih satu atau beberapa gambar JPEG dari galeri ponsel.
    *   **Delete Overlay (Button):** Tombol silang kecil (`xmark.circle.fill`) di sudut kanan atas setiap thumbnail. Mengetuk tombol ini memunculkan alert konfirmasi: *"Hapus foto ini dari produk?"*.
    *   **Upload Progress Overlay:** Saat gambar sedang diunggah, thumbnail bersangkutan menampilkan spinner (`ProgressView`) di atas visual semi-transparan.
*   **Validation Rules:**
    *   **Format File:** Hanya menerima tipe file JPEG. Foto dari PhotosPicker (format HEIC/PNG/dll) dikonversi secara otomatis di sisi client ke format JPEG.
    *   **Maksimum File Size:** Maksimum biner gambar yang diunggah ke jaringan adalah **1.8 MB (1,887,436 bytes)**. Jika file asli berukuran lebih besar, client-side compressor otomatis mengurangi kualitas dan dimensi resolusi gambar hingga memenuhi syarat sebelum mengirim request API.
*   **State & Progressive Disclosure:**
    *   Tombol hapus dinonaktifkan ketika proses unggah foto lain sedang aktif untuk menghindari tabrakan state.
    *   Jika unggah gagal, tampilkan toast merah bertuliskan alasan error (misal: "Koneksi terputus" atau "Format file tidak didukung").

## 4. API Contract (FastAPI Proxy to GCS)
Backend FastAPI bertindak sebagai proxy aman yang menerima payload multipart form dari iOS, memvalidasi hak akses (JWT token), lalu mengunggahnya ke bucket Google Cloud Storage menggunakan library `google-cloud-storage`.

### 4.1. Endpoint: Upload Image
*   **Method & Path:** `POST /api/v1/products/{sku}/sizes/{sizeId}/images`
*   **Request Headers:** `Authorization: Bearer <JWT_TOKEN>`
*   **Request Body (`multipart/form-data`):**
    *   `file`: Binary Data (JPEG, max 1.8 MB)
*   **Backend Logic:**
    1. Memverifikasi hak akses pengguna (berdasarkan token JWT).
    2. Membuat nama file unik di GCS: `products/{sku}/sizes/{sizeId}/{uuid}.jpg`.
    3. Mengunggah biner file langsung ke bucket GCS dengan metadata `Content-Type: image/jpeg`.
    4. Menyimpan record baru ke tabel `product_size_image`.
    5. Mengembalikan data record yang tersimpan.
*   **Response (201 Created):**
    ```json
    {
      "id": "e9fae3d1-4db3-431c-8cb0-b7dc4901ba32",
      "product_size_id": "87b074e0-798b-4b2a-b6b5-0c30a574ff0b",
      "image_url": "https://storage.googleapis.com/oura-studio-prod-bucket/products/SCR-01/sizes/87b074e0-798b-4b2a-b6b5-0c30a574ff0b/e9fae3d1-4db3-431c-8cb0-b7dc4901ba32.jpg",
      "created_at": "2026-09-05T12:00:00Z"
    }
    ```

### 4.2. Endpoint: Delete Image
*   **Method & Path:** `DELETE /api/v1/products/{sku}/sizes/{sizeId}/images/{imageId}`
*   **Request Headers:** `Authorization: Bearer <JWT_TOKEN>`
*   **Backend Logic:**
    1. Memverifikasi hak akses pengguna.
    2. Mengambil record `product_size_image` berdasarkan `imageId`.
    3. Menghapus objek fisik dari bucket GCS (mendapatkan nama objek dari substring `image_url`).
    4. Menghapus baris data dari database `product_size_image`.
*   **Response (204 No Content):**
    *(Empty response)*

### 5.2. Helper Kompresi Dinamis (`ImageCompressor.swift`)
Membuat struktur helper baru untuk otomatis mengubah tipe file ke JPEG dan menurunkan kualitas/dimensi biner gambar di bawah batas 1.8 MB:

```swift
import UIKit

struct ImageCompressor {
    /// Kompresi gambar menjadi biner JPEG yang berukuran di bawah maxBytes (default 1.8 MB)
    static func compressToJPEG(image: UIImage, maxBytes: Int = 1887436) -> Data? {
        var quality: CGFloat = 1.0
        // Konversi tipe file apa pun (HEIC, PNG) ke JPEG biner dasar
        guard var data = image.jpegData(compressionQuality: quality) else { return nil }
        
        // Skenario A: Jika sudah di bawah 1.8 MB, kembalikan langsung
        if data.count <= maxBytes {
            return data
        }
        
        // Skenario B: Turunkan kualitas biner secara progresif (1.0 -> 0.1)
        while data.count > maxBytes && quality > 0.1 {
            quality -= 0.15
            if let compressedData = image.jpegData(compressionQuality: quality) {
                data = compressedData
            }
        }
        
        // Skenario C: Jika kualitas 0.1 masih terlalu besar, kurangi resolusi pixel (downscale) secara berulang
        var size = image.size
        while data.count > maxBytes && size.width > 200 {
            size = CGSize(width: size.width * 0.8, height: size.height * 0.8)
            
            let format = UIGraphicsImageRendererFormat()
            format.scale = 1
            let renderer = UIGraphicsImageRenderer(size: size, format: format)
            let resizedImage = renderer.image { _ in
                image.draw(in: CGRect(origin: .zero, size: size))
            }
            
            quality = 0.8
            if let resizedData = resizedImage.jpegData(compressionQuality: quality) {
                data = resizedData
                // Lakukan kompresi biner lagi pada gambar yang sudah dikecilkan dimensinya
                while data.count > maxBytes && quality > 0.1 {
                    quality -= 0.15
                    if let compressedData = resizedImage.jpegData(compressionQuality: quality) {
                        data = compressedData
                    }
                }
            }
        }
        
        return data.count <= maxBytes ? data : nil
    }
}
```

### 5.3. Penambahan di `APIService.swift`
Menambahkan dua fungsi jaringan baru untuk mengunggah biner dan menghapus gambar:

```swift
func uploadProductSizeImage(sku: String, sizeId: UUID, imageData: Data) async throws -> ProductSizeImage {
    // Membangun multipart/form-data request secara native menggunakan URLSession
    let boundary = "Boundary-\(UUID().uuidString)"
    var request = try buildRequest(path: "/products/\(sku)/sizes/\(sizeId)/images", method: "POST")
    request.setValue("multipart/form-data; boundary=\(boundary)", forHTTPHeaderField: "Content-Type")
    
    var body = Data()
    body.append("--\(boundary)\r\n".data(using: .utf8)!)
    body.append("Content-Disposition: form-data; name=\"file\"; filename=\"image.jpg\"\r\n".data(using: .utf8)!)
    body.append("Content-Type: image/jpeg\r\n\r\n".data(using: .utf8)!)
    body.append(imageData)
    body.append("\r\n".data(using: .utf8)!)
    body.append("--\(boundary)--\r\n".data(using: .utf8)!)
    
    request.httpBody = body
    
    let (data, response) = try await perform(request)
    try validate(response: response, expectedStatus: 201)
    
    let decoder = JSONDecoder()
    decoder.dateDecodingStrategy = .iso8601
    return try decoder.decode(ProductSizeImage.self, from: data)
}

func deleteProductSizeImage(sku: String, sizeId: UUID, imageId: UUID) async throws {
    let request = try buildRequest(path: "/products/\(sku)/sizes/\(sizeId)/images/\(imageId)", method: "DELETE")
    let (_, response) = try await perform(request)
    try validate(response: response, expectedStatus: 204)
}
```

## 6. Verification & Test Plan

### 6.1. Unit Test: `ImageCompressorTests.swift`
Menguji keandalan fungsionalitas pengubah ukuran dan kompresor gambar:
*   **TC-COMP-01 (No-op):** Memastikan gambar JPEG dengan ukuran asli di bawah 1.8 MB tidak dikompresi berlebihan dan biner aslinya tetap valid.
*   **TC-COMP-02 (Format Conversion):** Memasukkan gambar biner format PNG / HEIC dan memvalidasi output berupa data JPEG valid.
*   **TC-COMP-03 (Auto-Compression Limit):** Memasukkan gambar berukuran besar (misal 5 MB atau 10 MB) dan memvalidasi biner keluaran mutlak **<= 1,887,436 bytes** (1.8 MB).

### 6.2. Sanity Test Scenarios
*   **TC-SAN-01 (Upload Flow):** Mengetuk `PhotosPicker`, memilih gambar, memproses kompresi otomatis, melihat skeleton pemuatan aktif, hingga gambar berhasil terunggah dan ditampilkan di carousel.
*   **TC-SAN-02 (Delete Flow):** Mengetuk tanda silang merah, menyetujui dialog konfirmasi penghapusan, dan memverifikasi bahwa item terhapus dari UI serta tidak lagi muncul saat memuat ulang halaman.
