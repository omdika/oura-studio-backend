## Task 7: Fallback HPP di Sales Order — Level 3

`get_hpp_for_sale()` sekarang punya 4 tier:

| Tier | Sumber | hpp_source |
|---|---|---|
| 1 | `production_batch_item` terkonfirmasi (snapshot) | `"batch"` |
| 2 | `PatternSpec` aktif — estimasi via `estimate_fabric_cost_per_piece_from_rate()` | `"pattern_spec"` |
| 3 | `manual_hpp_*` di `product_sizes` | `"manual"` |
| 4 | Tidak ada HPP | hpp_total=0, `"none"` |

Kode Tier 3 (ditambahkan setelah Tier 2):
```python
if not hpp_found and size.has_manual_hpp:
    hpp_total    = size.manual_hpp_total
    hpp_fabric   = size.manual_hpp_fabric or 0
    hpp_pooled   = size.manual_hpp_pooled or 0
    hpp_hardware = size.manual_hpp_hardware or 0
    hpp_labor    = size.manual_hpp_labor or 0
    hpp_overhead = size.manual_hpp_overhead or 0
    hpp_source   = "manual"
```

## Fix: GET /reports/margin-ranking

**Bug:** Endpoint hanya mempertimbangkan produk dengan batch HPP → `[]` untuk produk
manual HPP.

**Fix:** Implementasikan `get_hpp_for_margin(size, db)` (reuse logika dari
`get_hpp_for_sale()`, tanpa nuance stok) dan loop semua `ProductSize` dengan
`selling_price > 0` dan `is_archived == False`:

```python
results = []
for size in db.query(ProductSize).filter(selling_price > 0, is_archived == False):
    hpp = get_hpp_for_margin(size, db)
    if hpp <= 0:
        continue
    margin = (size.selling_price - hpp) / size.selling_price
    results.append({...})
results.sort(key=lambda x: x["margin_pct"], reverse=True)
```

---

## Fix: avg_margin_pct di GET /reports/dashboard

**Bug:** `avg_margin_pct` selalu 0 karena menggunakan logika lama (batch-only).

**Fix:** Gunakan `get_hpp_for_margin()` yang sama:
```python
valid_margins = []
for size in ProductSize.query.filter(selling_price > 0, is_archived == False):
    hpp = get_hpp_for_margin(size, db)
    if hpp > 0:
        margin = (size.selling_price - hpp) / size.selling_price
        valid_margins.append(margin)
avg_margin_pct = sum(valid_margins) / len(valid_margins) if valid_margins else 0.0
```
