# v2.8 — Sizes List: latest_hpp_breakdown + Stale-Draft Bug Fix (2026-08-08)
**Date:** 2026-08-08  
**Changed by:** Backend (reported by Frontend)  
**Status:** ✅ IMPLEMENTED

---

## Summary

Dua fix di `GET /products/{sku}/sizes` yang menyebabkan RINCIAN HPP card di iOS selalu kosong.

---

## Fix 1 — latest_hpp_breakdown di sizes list response

**Before:** `latest_hpp_breakdown` dan `margin_pct` hanya ada di detail endpoint (`GET /products/{sku}/sizes/{sizeId}`), tidak di list endpoint.

**After:** kedua field ditambahkan ke setiap item di array response list. iOS client menggunakan list endpoint (`fetchSizeToProductMap`) untuk enrichment — kalau field tidak ada di sini, RINCIAN HPP selalu kosong.

---

## Fix 2 — Stale-draft bug di "latest production item" lookup

**Before:** query untuk mencari HPP terbaru (`latest_hpp_breakdown`) tidak mem-filter `production_batch.status='confirmed'`. Jika sebuah draft batch baru ada untuk product_size yang sama setelah confirmed batch, hpp_* yang semua-nol dari draft batch akan mem-shadow HPP yang benar.

**After:** query difilter dengan `production_batch.status='confirmed'`.

`production_stock_qty` dan `manual_stock_qty` di sizes list response — tidak diimplementasikan di versi ini karena konflik dengan v2.4 yang menyatakan breakdown ini tidak diperlukan. Dilanjutkan di v2.10 setelah klarifikasi.
