# Version 3.62 - Galeri Utama Produk + Foto Wakil Per-Size ala Shopee

## 1. Problem / Opportunity
*   **Context:** Saat ini upload foto bersifat per-size (`product_size_image`, v3.50). Foto per-size TIDAK tampil di galeri utama — galeri utama/list hanya menampilkan foto size teratas. Ini melanggar aturan Shopee: foto varian HARUS juga ada di galeri utama (`images[]`), kalau tidak buyer tidak melihatnya di carousel utama. Selain itu urutan baris varian di file `.xlsx` export Shopee (v3.51) belum dijamin XS→XXL.
*   **Objective:** (a) Tambah galeri level produk (`product_image`, max 9, index 0 = cover) yang mengkurasi foto utama; (b) batasi pilihan Shopee per-size menjadi SATU wakil (`et_title_image_per_variation`); (c) isi kolom gambar template Shopee yang SUDAH ADA tanpa mengubah struktur template; (d) urutkan baris export + payload JSON XS→XXL.

## 2. User Flow & UX Specifications
*   **Entry Point 1 — Galeri Utama:** Section baru **"Galeri Utama (n/9)"** di `ProdukDetailView` header (di atas `sizesSection`). Entry sama seperti edit nama produk (tidak ada tab baru).
*   **Entry Point 2 — Foto Varian:** Section existing **"Foto Produk Varian"** di `ProdukSizeDetailView` / `ProdukSizeGroupView` tetap untuk upload multi-foto, TAPI tambah seleksi tunggal wakil Shopee.
*   **UI Components (reuse standard):**
    *   Galeri Utama: horizontal carousel thumbnail 80×80 (reuse pola v3.50), badge `Cover` di index 0, counter `n/9`, tombol `+` (PhotosPicker/Camera, reuse `ImageCompressor` 1.8MB JPEG), long-press/context-menu: `Jadikan Cover`, `Geser Kiri/Kanan` (reorder), `Hapus`. `canSave`: upload disabled saat `count >= 9` (tampilkan hint "Galeri penuh (9/9) — hapus/geser dulu").
    *   Foto Varian: tiap thumbnail dapat radio/check `Foto Shopee` (satu aktif per size). Tap radio baru = pindahkan pilihan (exclusive). State kosong diizinkan (belum pilih wakil). Tombol tambahan per thumbnail terpilih: `+ ke Galeri Utama` (atau otomatis — lihat State).
    *   `ProdukListView` thumbnail: tampilkan `cover` (`product_image where is_cover`, fallback image pertama galeri, fallback foto size pertama). Bukan lagi "foto size teratas".
    *   `ShopeeBulkUploadSheet`: tambah warning inline: "X produk tanpa cover", "Y varian tanpa foto Shopee", "Z produk >9 foto (dipotong)".
*   **Validation Rules (`canSave`):**
    *   Galeri utama max 9. Backend + frontend enforce (409 jika lebih).
    *   Satu size = maksimal SATU wakil Shopee. Pilih baru otomatis batalkan lama (atomic di backend via partial unique index).
    *   URL harus `https://` publik (GCS). HEIC/PNG dikonversi ke JPEG via `ImageCompressor`.
*   **State & Progressive Disclosure:**
    *   Saat user memilih wakil Shopee per-size → otomatis `upsert` URL itu ke `product_image` (dedupe by `image_url`) JIKA slot <9. Jika galeri penuh → toast kuning "Galeri penuh — foto wakil tersimpan di varian, tambahkan manual ke galeri" + arahkan buka Galeri Utama. Ini menegakkan aturan Shopee "every variant image MUST also be in gallery" tanpa memaksa.
    *   Hapus foto varian yang sedang jadi wakil → wakil dikosongkan (export sel itu kosong), entri galeri utama TIDAK ikut terhapus (kurasi independen).
    *   Hapus/ubah cover tidak mengubah wakil per-size.

## 3. Database Schema Changes (Supabase PostgreSQL)
*   **Affected Tables:** `product` (read-only ref), `product_size_image` (tambah flag), baru `product_image`.
*   **New / Modified Columns:**
    ```sql
    CREATE TABLE product_image (
        id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
        product_id UUID NOT NULL REFERENCES product(id) ON DELETE CASCADE,
        image_url TEXT NOT NULL,
        sort_order INT NOT NULL DEFAULT 0,
        is_cover BOOLEAN NOT NULL DEFAULT FALSE,
        created_at TIMESTAMPTZ NOT NULL DEFAULT now()
    );
    CREATE INDEX idx_product_image_product ON product_image(product_id, sort_order);
    CREATE UNIQUE INDEX uq_product_cover ON product_image(product_id) WHERE is_cover;

    ALTER TABLE product_size_image
        ADD COLUMN is_shopee_selected BOOLEAN NOT NULL DEFAULT FALSE;
    CREATE UNIQUE INDEX uq_size_shopee_selected
        ON product_size_image(product_size_id) WHERE is_shopee_selected;
    ```
*   **Invariants:** `sort_order` 0..n-1 rapat per produk (renormalize tiap reorder/delete). `is_cover` = baris `sort_order = 0` (backend jaga konsisten). Satu `is_shopee_selected = TRUE` per `product_size_id`.

## 4. API Contract (FastAPI)
*   **Endpoints galeri produk:**
    *   `GET /api/v1/products/{sku}/images` → `[{id, product_id, image_url, sort_order, is_cover, created_at}]` terurut `sort_order`.
    *   `POST /api/v1/products/{sku}/images` (`multipart/form-data`, field `file`, JPEG ≤1.8MB) → 201 record baru (append `sort_order = max+1`; jika galeri kosong otomatis `is_cover=TRUE`). 409 `GALLERY_FULL` jika sudah 9.
    *   `PATCH /api/v1/products/{sku}/images/{imageId}` body `{"is_cover": true}` atau `{"sort_order": n}` → 200. Set cover = pindah ke index 0 + renumber.
    *   `DELETE /api/v1/products/{sku}/images/{imageId}` → 204 + renumber; jika cover dihapus, baris 0 baru jadi cover.
*   **Endpoint wakil per-size (tunggal):**
    *   `PATCH /api/v1/products/{sku}/sizes/{sizeId}/images/{imageId}/select` body `{"selected": true|false}` → 200. `true` = set eksklusif (unset lain dalam 1 transaksi); sekaligus trigger auto-upsert ke `product_image` (dedupe, hormati limit 9 — jika penuh kembalikan `200` + field `gallery_synced: false, gallery_reason: "FULL"`).
    *   `POST /api/v1/products/{sku}/sizes/{sizeId}/images/from-gallery` body `{"gallery_image_id": UUID, "set_as_wakil": true}` → 201. Menyalin foto galeri utama ke varian (URL sama, baris baru; dedupe by URL) + jadikan wakil eksklusif. Response `SizeImageSelectOut` (`gallery_synced: true`).
    *   **Validation & Errors:** 404 produk/size/image, 409 `GALLERY_FULL`, 422 file bukan JPEG/oversize.
*   **Endpoint payload JSON baru (untuk AI agent, TANPA sentuh Excel):**
    *   `GET /api/v1/products/{sku}/shopee-payload`
    *   **Backend Logic (Payload Rule, persis request user):**
        1. Ambil `cover` (`product_image` is_cover) + wakil tiap size (`is_shopee_selected`, terurut XS→XXL) → dedupe by URL → potong max 9 → `images[]` (index 0 = cover).
        2. `models[]` = tiap size aktif (`selling_price>0`), terurut XS→XXL: `{"name": size_label, "price": selling_price, "stock": current_stock_qty, "image_url": wakil_atau_null}`.
        3. Sort key XS→XXL: `["XXS","XS","S","M","L","XL","XXL","XXXL"]`, label lain alfabetis setelahnya (mirror `sizeLabelSortKey` iOS).
    *   **Response (200):** `{"images": [...max 9], "models": [{"name","price","stock","image_url"}]}` (contoh di request user).
*   **Endpoint Excel existing (`GET /api/v1/products/shopee-bulk-upload`) — HANYA isi sel, JANGAN ubah struktur:**
    *   Template tetap diduplikasi dari master resmi, tulis mulai **Baris 7**, sheet `Template`, baris 1–6 byte-identical (verifikasi di test).
    *   Urutan baris per produk = XS→XXL (sort key di atas). Produk diurut stabil by `sku`/created.
    *   Mapping kolom gambar (kolom SUDAH ADA di template — `templateShopeeBulk - Template.csv`):
        *   Baris variasi PERTAMA per produk: `ps_product_name/description/sku_parent` diisi (aturan v3.51 tetap); `ps_item_cover_image` = `images[0]` (cover); `ps_item_image_1..8` = `images[1..8]`; `et_title_image_per_variation` = wakil size baris itu (atau kosong).
        *   Baris variasi KE-2 dst (KOREKSI user): `ps_product_name/description/sku_parent/ps_item_image_2..8` dikosongkan; **`ps_item_cover_image` = wakil size baris itu; `ps_item_image_1` = wakil size baris itu (duplikat sama);** `et_title_image_per_variation` = wakil size baris itu. Jika size belum pilih wakil → ketiga sel dikosongkan.
        *   Kolom non-gambar (`ps_price`, `ps_stock`, `ps_sku_short=[SKU]-[SIZE]`, berat/dimensi/logistik) tetap per v3.51.

## 5. Frontend Changes (SwiftUI)
*   **Codable Models & APIService (`ProductModels.swift`, `APIService.swift`):**
    ```swift
    struct ProductImage: Codable, Identifiable, Hashable {
        let id: UUID; let productId: UUID; let imageUrl: String
        let sortOrder: Int; let isCover: Bool; let createdAt: Date
        enum CodingKeys: String, CodingKey {
            case id; case productId = "product_id"; case imageUrl = "image_url"
            case sortOrder = "sort_order"; case isCover = "is_cover"; case createdAt = "created_at"
        }
    }
    // ProductSizeImage += let isShopeeSelected: Bool? (coding key is_shopee_selected)
    struct ShopeePayload: Codable { let images: [String]; let models: [ShopeeModel] }
    struct ShopeeModel: Codable { let name: String; let price: Double; let stock: Int; let imageUrl: String? }
    ```
    *   `APIService`: `getProductImages(sku)`, `uploadProductImage(sku,data)`, `patchProductImage(sku,imageId,isCover/sortOrder)`, `deleteProductImage(...)`, `selectSizeShopeeImage(sku,sizeId,imageId,selected)`, `getShopeePayload(sku)`. Semua dengan `loggedDecode` + `validate` pola existing.
*   **Views:**
    *   `ProdukDetailView.swift`: tambah `GallerySection` (cover carousel + `PhotosPicker`), gunakan `ImageCompressor.compressToJPEG`, reuse `ProductImageViewer` untuk fullscreen. `loadSizes()` juga `async let` load `getProductImages`. Menu thumbnail galeri + toolbar viewer punya submenu **Masukkan ke Varian** (submenu per ukuran → `assignGalleryToVariant`). Badge ukuran pemakai (wakil) di tiap thumbnail galeri.
    *   `ProdukSizeDetailView` (di file yang sama): overlay radio `Foto Shopee` di tiap thumbnail + handler `selectSizeShopeeImage` + auto-sync notice.
    *   `ProdukListView.swift` (`ProductGroupRow`): thumbnail = cover (perlu `allProductImages: [UUID: [ProductImage]]` cache atau sertakan `cover_image_url` di `GET /products` — pilih cache map agar TANPA migrasi list endpoint; lakukankah? Minimal: fetch covers lazily per produk visible).
    *   `ShopeeBulkUploadSheet.swift`: tampilkan warning cover/wakil/overflow dari preflight `GET /products/shopee-payload` per produk (client-side aggregate) sebelum download.

## 6. Verification & Test Plan
*   **Smoke Test:** Build OK; tab Produk → detail produk → Galeri Utama muncul; tambah/hapus foto tidak crash; export Shopee tetap unduh `.xlsx`.
*   **Sanity Test Scenarios:**
    *   TC-01 Upload cover: produk kosong → upload 1 foto → jadi cover (badge Cover, `images[0]` di payload).
    *   TC-02 Wakil tunggal: size M punya 3 foto → pilih foto #2 → radio pindah, pilih #3 → #2 otomatis off; `PATCH select` kedua sukses; hanya 1 `is_shopee_selected` di DB.
    *   TC-03 Auto-sync galeri: pilih wakil L → URL muncul di galeri utama (dedupe: pilih 2x tidak dobel). Galeri 9/9 → pilih wakil baru → toast penuh + `gallery_synced=false`.
    *   TC-04 Excel baris 1 vs 2+: produk 3 size (S,M,L terurut XS→XXL walau dibuat acak) → baris 7 (S): cover+image_1..8 penuh + `et_title_image_per_variation`=wakil S; baris 8 (M): nama/desc kosong, `ps_item_cover_image`=wakil M, `ps_item_image_1`=wakil M, `image_2..8` kosong; baris 9 (L) sama. Header baris 1–6 identik dengan master (bandingkan hash/openpyxl).
    *   TC-05 JSON payload: `GET /{sku}/shopee-payload` → `images` = `[cover, wakil XS..XXL unik][:9]`, `models` terurut XS→XXL dengan `price/stock/image_url` benar; cocok dengan sel Excel baris-baris itu.
    *   TC-06 List teratas: `ProdukListView` tampilkan cover (bukan foto size pertama); size tanpa cover fallback benar.
