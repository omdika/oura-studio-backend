## Latar Belakang

`POST /production-batches` tanpa `cutting_layout_id` membuat batch kosong. Tidak ada endpoint untuk
menambah item ke batch yang sudah ada. iOS client saat ini tidak bisa membuat batch manual yang berguna —
user hanya bisa mengkonfirmasi batch kosong (menghasilkan data HPP salah) atau menghapusnya.

Dua endpoint baru menutup gap ini:

---

## Endpoint Baru

### `POST /production-batches/{id}/items`

Menambah satu item ke batch yang masih draft.

**Request body:**
```json
{
  "product_size_id": "uuid",
  "qty_actual": 5
}
```

**Validasi:**
- `batch.status` harus `'draft'` — kembalikan 409 jika `'confirmed'`.
- `product_size_id` harus merujuk ke `ProductSize` yang ada — kembalikan 404 jika tidak.
- `qty_actual` harus ≥ 1 — kembalikan 422 jika 0 atau negatif.

**Logika server:**
1. Cari `PatternSpec` terbaru yang aktif (`is_active = true`) untuk `product_size_id` ini.
   - Jika ditemukan: gunakan sebagai `pattern_spec_id` di item baru.
   - Jika tidak ada: set `pattern_spec_id = null`.
2. Buat row `production_batch_item` baru:
   - `production_batch_id` = `{id}` dari path
   - `product_size_id` = dari request
   - `pattern_spec_id` = dari langkah 1
   - `qty_actual` = dari request
   - `qty_suggested = null` (tidak ada cutting layout)
   - `fabric_cost_per_piece = null` (tidak ada cutting layout)
   - `hpp_fabric = 0`, `hpp_pooled_material = 0`, `hpp_hardware = 0`, `hpp_labor = 0`,
     `hpp_overhead = 0`, `hpp_total = 0` — diisi nanti saat `POST /confirm`

**Response (200):** `BackendProductionBatchItem` shape yang sudah ada:
```json
{
  "id": "uuid",
  "product_size_id": "uuid",
  "pattern_spec_id": "uuid or null",
  "qty_actual": 5,
  "qty_suggested": null,
  "fabric_cost_per_piece": null,
  "hpp_fabric": 0.0,
  "hpp_pooled_material": 0.0,
  "hpp_hardware": 0.0,
  "hpp_labor": 0.0,
  "hpp_overhead": 0.0,
  "hpp_total": 0.0
}
```

**Error responses:**
- `404` — `production_batch` atau `product_size` tidak ditemukan
- `409` — batch sudah confirmed

---

### `DELETE /production-batches/{id}/items/{item_id}`

Menghapus satu item dari batch yang masih draft.

**Validasi:**
- `batch.status` harus `'draft'` — kembalikan 409 jika `'confirmed'`.
- `item_id` harus milik batch `{id}` — kembalikan 404 jika tidak ditemukan atau bukan milik batch ini.

**Logika server:**
- Hard delete row `production_batch_item` — aman karena batch masih draft, belum ada
  `stock_ledger` atau `remaining_length_cm` yang diubah (itu hanya terjadi saat confirm).

**Response:** `204 No Content`

**Error responses:**
- `404` — item tidak ditemukan atau bukan milik batch ini
- `409` — batch sudah confirmed

## Catatan untuk Implementasi

### Confirm saat `pattern_spec_id = null`

`POST /production-batches/{id}/confirm` menggunakan `pattern_spec_id` untuk menghitung
`hpp_labor` dan `hpp_hardware`. Jika sebuah item punya `pattern_spec_id = null`:
- `hpp_labor = 0`, `hpp_hardware = 0` — dianggap tidak ada resep.
- `hpp_fabric = 0` — tidak ada `cutting_layout_item.cost_per_piece`.
- `hpp_total = hpp_pooled_material + hpp_overhead` saja.

Ini bukan error — HPP yang tidak lengkap lebih baik dari konfirmasi yang diblokir. Frontend sudah
menampilkan peringatan jika HPP breakdown tidak lengkap.

### Tidak ada endpoint bulk

Tidak perlu `POST /production-batches/{id}/items/bulk`. iOS client mengirim request satu per satu
dan menangani partial failure di sisi UI — desain ini lebih sederhana dan tidak memerlukan
atomic batch insert.

### Catatan skema

Tidak ada perubahan skema. `production_batch_item` sudah punya semua kolom yang diperlukan:
- `qty_suggested NULLABLE` — sudah nullable di skema saat ini.
- `fabric_cost_per_piece` — kolom ini sudah ada di `BackendProductionBatchItem` response.
- `hpp_*` — semua sudah nullable-ready (bisa diset 0.0 untuk draft manual).

Pastikan `qty_suggested` di `production_batch_item` memang `NULLABLE` di Alembic model — di
beberapa versi awal mungkin NOT NULL. Jalankan migration jika perlu.

## Perubahan Section 4 (Production API Contract)

Tambahkan di bawah `PATCH /production-batches/{id}/items/{item_id}`:

```
POST   /production-batches/{id}/items
  body: { product_size_id: UUID, qty_actual: Int }
  -- only allowed while batch status='draft'; 409 if confirmed
  -- pattern_spec_id auto-resolved to latest active spec for product_size_id, or null if none
  -- all hpp_* fields initialized to 0.0 (computed at confirm)
  → 200: BackendProductionBatchItem shape

DELETE /production-batches/{id}/items/{item_id}
  -- only allowed while batch status='draft'; 409 if confirmed
  -- hard-delete: safe because confirm hasn't run yet (no stock_ledger/remaining_length_cm touched)
  → 204 No Content
```
