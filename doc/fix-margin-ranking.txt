FIX: GET /reports/margin-ranking kosong + avg_margin_pct di dashboard 0%
=========================================================================

Frontend memanggil endpoint ini dan mendapat response 200 OK dengan body [].
Produk yang HPP-nya diset lewat ScanToStockSheet (manual_hpp_* fields) tidak
muncul di ranking, meskipun selling_price dan manual_hpp sudah tersimpan.

Endpoint seharusnya mengembalikan SEMUA product_sizes yang punya selling_price
+ HPP dari sumber manapun, tidak hanya yang punya batch produksi terkonfirmasi.

---

## Response shape yang diharapkan frontend

GET /reports/margin-ranking?sort=margin_pct

Response (array, sudah disort descending margin_pct):
[
  {
    "product_size_id": "<uuid>",
    "product_name":    "Scrunchie Waffle",
    "size_label":      "S",
    "fabric_variant_name": "Waffle Blue",   // nullable
    "hpp_total":       18274.0,
    "selling_price":   30000.0,
    "margin_pct":      0.391                // (selling_price - hpp) / selling_price
  },
  ...
]

Hanya masuk jika:
  - selling_price IS NOT NULL AND selling_price > 0
  - hpp_total > 0 (dari sumber manapun, lihat prioritas di bawah)

---

## Prioritas sumber HPP (sama dengan get_hpp_for_sale)

Untuk setiap ProductSize, hitung hpp_total dengan urutan fallback ini:

  1. Batch HPP — dari ProductionBatch terkonfirmasi yang terkait size ini
     (field: avg_hpp_per_unit atau unit_cost di ProductionBatch/CuttingLayout)

  2. PatternSpec estimate — dari active PatternSpec untuk size ini
     Gunakan fungsi yang sama dengan get_hpp_for_sale() Tier 2:
     estimate_fabric_cost_per_piece_from_rate() per fabric di spec.fabrics,
     tambah komponen, pooled rates, labor, overhead dari settings.
     (Persis seperti yang sudah dilakukan di sales HPP fallback)

  3. Manual HPP — dari kolom manual_hpp_* di tabel product_sizes:
     hpp_total = manual_hpp_fabric + manual_hpp_pooled + manual_hpp_hardware
               + manual_hpp_labor + manual_hpp_overhead
     Masukkan jika total > 0.

  4. Skip — jika tidak ada HPP dari tier 1-3, jangan masukkan size ini
     ke hasil ranking (tidak ada data yang bisa ditampilkan).

---

## Cara implementasi yang disarankan

Pseudocode di handler:

  results = []
  for size in ProductSize.query.filter(selling_price > 0, is_archived == False):
      hpp = get_hpp_for_margin(size, db)  # fungsi baru, logika sama dengan get_hpp_for_sale
      if hpp <= 0:
          continue
      margin = (size.selling_price - hpp) / size.selling_price
      results.append({
          "product_size_id":    size.id,
          "product_name":       size.product.name,
          "size_label":         size.size_label,
          "fabric_variant_name": size.fabric_variant_name,
          "hpp_total":          hpp,
          "selling_price":      size.selling_price,
          "margin_pct":         margin
      })

  # Sort by margin_pct descending
  results.sort(key=lambda x: x["margin_pct"], reverse=True)
  return results

Fungsi get_hpp_for_margin(size, db) bisa me-reuse get_hpp_for_sale() yang
sudah ada di sales service, atau extract logika fallback-nya ke fungsi shared.

## Cara verifikasi

1. Pastikan ada product_size dengan:
   - selling_price > 0
   - manual_hpp_fabric + manual_hpp_labor + ... > 0
   (Produk yang diset via ScanToStockSheet → Simpan HPP otomatis terisi)

2. Panggil endpoint:
   GET /reports/margin-ranking?sort=margin_pct
   Authorization: Bearer <token>

   Seharusnya mengembalikan array berisi produk tersebut, bukan [].

3. Verifikasi margin_pct benar:
   selling_price = 30000, hpp = 18274
   margin_pct = (30000 - 18274) / 30000 = 0.3909 ≈ 0.391 ✓

## Bug #2: avg_margin_pct di GET /dashboard selalu 0 / null

Dashboard menampilkan "0% margin" karena backend mengembalikan:
  { ..., "avg_margin_pct": 0.0 }  atau  "avg_margin_pct": null

Frontend menggunakan `dashboard?.avgMarginPct ?? 0` — jika null/0, tampil 0%.

### Fix

Gunakan fungsi get_hpp_for_margin() yang sama (dari fix #1 di atas) untuk
menghitung avg_margin_pct di endpoint dashboard:

  valid_margins = []
  for size in ProductSize.query.filter(selling_price > 0, is_archived == False):
      hpp = get_hpp_for_margin(size, db)
      if hpp > 0:
          margin = (size.selling_price - hpp) / size.selling_price
          valid_margins.append(margin)

  avg_margin_pct = sum(valid_margins) / len(valid_margins) if valid_margins else 0.0

Field response dashboard yang perlu diupdate:
  "avg_margin_pct": 0.391   // rata-rata margin semua produk dengan HPP valid
